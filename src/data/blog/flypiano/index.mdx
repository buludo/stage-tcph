# 前言

音樂史上偉大作曲家們，用他們擅長的音符，動人的、激昂的、悲嘆的譜出不計其數的樂曲，用音符透露出歡快雀躍、平靜或深沉、孤單、悲傷甚至嫉妒，今晚我們用音樂和您分享我們喜愛的浪漫「琴」事。

《似曾相識》(Somewhere In Time) 是1980年由導演Jeannot Szwarc執導的奇幻電影，算是第一部浪漫的穿越劇電影，而電影引用音樂家拉赫曼尼諾夫(Sergei Rachmaninov，1873-1943)的《帕格尼尼主題狂想曲》的第18段變奏，優美動聽的旋律，配合劇中男女主角纏綿悱惻，跨越時空的愛情，至今讓人難以忘懷，今年適逢拉赫曼尼諾夫150週年誕辰，以此紀念這位俄羅斯浪漫主義的代表作曲家。

《假面舞會》Masquerade為俄國天才詩人雷蒙托夫（Mikhail Yurievich Lermontov）根據莎士比亞的四大悲劇《奧塞羅》(Othello)改寫而成的戲劇，由哈察都量(Aram Khachaturian，1903-1978)擔任作曲配樂。描寫帝俄時代貴族生活的虛偽腐化，嫉妒的丈夫誤以為心愛的妻子出軌，最終將她殺死。哈察都量為此劇譜曲的圓舞曲以悲劇性的濃烈情感、與漂浮狂乖的哀愁交織而成，充滿抒情、奔放的旋律盤旋其中。

# 前言

柴科夫斯基(P. I. Tchaikovsky，1840-1893)的經典歌劇《尤金·奧涅金》(Eugene Onegin)，原著是俄國文豪普希金(A.S. Pushkin，1799-1837)所寫的敘事詩，描寫的是貴族尤金·奧涅金的身世與愛情，第三幕開頭的波蘭舞曲是音樂會常常單獨演奏的曲目，讓人的耳朵為之一亮的華麗風格，彷彿來到了富麗堂皇的舞會之中。透過迪士尼動畫《美女與野獸》中首首動聽的歌曲，提醒著我們真正的美是來自內在、是無私的奉獻以及對人的關懷，期許我們為這個世界增添更多的善良美好。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-08/05a5726a-97ed-4c5f-8a45-2b4b68640609/4d01dcebc3daf407ec6e75315ad8cb8949bb8c23d7562e472b747bb7ea43a658.jpg)

本校創立音樂社團自60年代起延續至今，約計深耕40多年光景，民權音樂團隊的發展、經營、延續，從家長、校友、老師和孩子口中，充滿讚許、喜樂、甜美，留下許多美好的故事和回憶，續傳佳話。

回顧每年上學期各社團都卯足全力，為本校爭取代表臺北市參加全國賽的機會，並於各項競賽中大放異彩，榮獲佳績。音樂團隊老師的承擔和用心，展現在學生的表演成果上。團隊中默默投入協助比賽及展演準備工作的家長們，看見老師長期的付出與用心，在孩子畢業後，因著感動自願留下來持續幫忙。在民權學習音樂的孩子是有福的！團隊老師為孩子安排多樣舞台，透過展演，建立自信，並將音樂展演延續到社區舞台，回饋社會讓人心感動！老師們無盡付出的辛苦，已非是專業工作的承擔，是喜樂承載民權音樂教育傳統及特色延續的使命，音樂和民權已成生命一體。

近兩年民權國小榮獲優質學校學生學習、資源統整和校園營造獎項，多元社團-權能展才課程的量身訂做是希望民權的孩子在學校生活中，能學習一項專長，伴隨孩子一生帶著走的能力！校園裡歌聲、樂聲、讀書聲、跑步聲的傳統將精彩延續，我們再次全力以赴，為音樂深耕民權。誠摯邀請大朋友小朋友參與音樂社團的年度音樂會，即將呈現最棒的學習成果，記得給孩子最熱情的掌聲，給老師最大的支持！期待與音樂相遇，讓生命豐富，讓愛延續！

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-08/05a5726a-97ed-4c5f-8a45-2b4b68640609/6acbb5f52e0e342c102f30e5eb998a36df1edbc5ecb6241b0d2dea100210d1e1.jpg)

總說學音樂的孩子不會變壞，但我覺得應該說，學音樂的孩子身邊充滿了愛。

學習樂器本身是件孤獨的事，必須耐著性子，一個音練過一個音，音準了還得符合節拍，正確了以後必須熟悉順暢，熟練了就要開始琢磨情感，演奏出自己的詮釋與想法。幾天沒練習，生疏了就算別人聽不出來，自己也心裡有數。所以練琴得是每天的功課，重複著一樣的段落曲調，從一個個音節串聯成曲子。不管是哪一種樂器，甚至合唱，都得靠平日勤練才能累積出美妙的樂音。

而老師們的悉心指導、家人們從旁鼓勵陪伴、同儕團隊間的默契與交流，就是孤獨的音樂路上最美麗的風景，搖旗吶喊著，支持孩子們堅持往下走。

民權音樂社團裡的教師團隊總是這樣溫暖的存在，當孩子鬆懈時盡責督促，在孩子卡關時耐心帶領。一步步陪伴孩子從五音不全到樂音悠揚，稚嫩可愛的表情轉換為專業投入的眼神。每年的成果發表都是一次愛的凝聚，不僅用音符把孩子們聚在一起，也把家人帶入音樂廳，讓音樂豐富彼此的話題。

很幸運地，我自己的兩個孩子也在民權啟蒙了音樂之路，從第一個舞臺開始漸漸站穩腳步，與志同道合的夥伴們一起擁有豐富充實的回憶。感謝民權師長們用愛灌溉，感謝各社團背後強大的家長後援會。有這麼多的愛圍繞陪伴，民權的音樂社團才能百花齊放。

用音樂滋養生命、豐富視野，將會是孩子人生路上溫暖相伴的珍貴寶藏。

# 台北城市愛樂

台北城市愛樂成立於2012年，創團賴宜佳老師鑒於弦樂的多樣化演出，能激起更多愛樂民眾的迴響，因此邀約了弦樂王博仁老師、管樂知名指揮老師陳一夫老師及民生社區管樂團指揮尤金順老師情義協演，全力推廣更具有音樂教育的特別意義與功能的演出活動。

2013年6月第一次在中山堂中正廳演出，即得到熱烈的迴響，之後每年在中山堂定期舉辦音樂會，並廣邀臺灣傑出的音樂家一同合作演出，有指揮家許澀心、指揮家邱明宏、指揮家陳玟蓉、指揮家簡伯修、小提琴家朱育佑、手風琴演奏家陳俐瑾、小提琴家游山、小提琴家歐之瑀等。有這麼一群老師，他們從臺灣各地聚集在臺北這座喧鬧的城市中，努力用音樂中的真、善、美來教育我們的下一代。

2014年9月第一次在市政府親子劇場舉辦大提琴重奏音樂會，結集小小孩與老師群所編製出的50人大提琴團，首次演出即獲得大眾熱烈的回應，並應邀參與至Bellavita寶麗廣場聖誕活動、SOGO復興館的社區藝文活動演出。我們也與各地學子們做音樂交流：2016年1月及2017年2月赴香港、大阪，在香港理工大學、伊丹市立文化會館作交流演出2018年7月，城市愛樂至日本參加富士山河口湖音樂祭，於國際青少年交流音樂會演出。我們期盼以音樂來減輕生活上的壓力，用樂曲來豐富枯涸的心靈，邀請這城市的人們一起沉浸在美妙的旋律裡！

2013.06.11 中山堂中正廳「琴定。台北」音樂會自幼習琴，從小進入音樂班就讀即展現音樂天份。熱衷參與樂團演出，多次受邀至國家音樂廳、國家戲劇院、各縣市文化中心參與演出。在學習音樂之路穩紮穩打，有著深厚的基礎，曾獲選參與臺灣青少年交響樂團至歐洲巡迴演出，足跡踏遍奧地利、法國、匈牙利等國際級音樂廳，也受邀至總統府介壽音樂會參與演出。第一名進入台灣師大音樂研究所指揮組，之後多次與師範大學管弦樂團合作演出，並獲邀指揮新銳作曲家之作品發表。

熱於學習的她在忙碌的工作之虞不忘學習，參加美國參加巴德大學Bard College參加指揮音樂節，受Harold Farbermann、Apo Hsu、Raymond Harvey等指揮家指導，深入地鑽研指揮之藝術。每次音樂會在舞臺上展現的指揮魅力與熱情，除在樂曲表現豐沛的生命力外，其豐富迷人的肢體語言與表情對音樂的詮釋細膩，引領臺下的每一位觀眾沈浸在音樂之中。對音樂與美感教育的培育與推動始終充滿活力，創立台北城市愛樂，希望藉由樂音與群眾作美的交流，豐富民眾的藝術生活，傳送人人愛樂的理念。

自幼習樂的李泰和五歲學習鋼琴，六歲開始接觸小提琴，十歲就讀音樂班深深為中提琴富變化的淳厚音色所吸引，主修中提琴在校期間表現屢獲獎，資賦優異以第一名之成績甄試保送輔仁大學音樂系。曾師承趙永男老師、黃文慶老師、潘輝皓老師、林文也老師、姚元教授、何君恆教授等。2003年赴法國巴黎深造，以第一名成績獲得RUEIL-MALMAISON音樂院高級演奏家文憑、傑出演奏家文憑、評審並以一致通過給與最優異成績畢業。除自我對演奏有衷情的執著，不定期舉辦個人獨奏會外，對台灣音樂教育環境的營造亦不遺餘力，現為臺灣室內樂藝術推廣協會會員，並任教於基隆高級中學音樂班、中平國中音樂班、青山國民中小學、民權國小、汐止國小、榮富國小等中小提琴分部指導老師。

輔仁大學音樂系畢業主修中提琴，在校期間曾隨郭聯昌、陳廷輝，張正木教授們帶領台灣樂藝管弦樂團赴馬新巡迴演出。

2003年帶領明湖國中弦樂團參加內湖音樂嘉年華會於國防醫學院致德堂演出，2005-2009年為臺中市交響樂團、圓滿室內樂團中提琴手。

亦隨中市府團隊赴美亞特蘭大、舊金山、馬邵爾群島、港澳等地為城市交流演出。

目前於民權國小、碧湖國小、汐止國小、麗湖國小弦樂團合奏、分部個別指導教師。

# 民權國小弦樂團

民權國小弦樂團成立於民國87年9月，這些年來感謝劉益麟校長、紀清珍校長、曾文錄校長、吳國基校長以及各處室主任的大力支持、級任老師的配合、家長們的協助，使得樂團才能有今天的規模與成績。賴宜佳老師為現任負責老師，加上專業的外聘老師團隊，以培養孩子樂器演奏的能力，增進美感的學習與自我能力的啟發為目標。為增進孩子們的音樂視野，另與管樂團部份學生組成管弦樂團，屢次在音樂比賽中獲得優異的成績、演出獲得熱烈掌聲與回響，在在展現小朋友音樂學習上的無窮潛力。團員們熱心參與各項活動，曾應臺北市文化局之邀參加「兒童音樂嘉年華」活動於市政府廣場表演、「嘉義弦樂節」演出以及擔任「市長獎頒獎典禮」大會樂隊；我們也很開心能在空軍聯隊端午節活動、松山機場報佳音、松山長老教會社區藝文音樂會、臺安醫院聖誕節點燈活動等社區活動中參與演出。但願本團能獲得家長與社會大眾的迴響，希望藉著美的樂聲喚起大家對音樂的喜好與欣賞，促使人人愛樂的意念，從培養學生的美感經驗，進而變化社會風氣。
