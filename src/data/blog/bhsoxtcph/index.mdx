# 關於雙城琴緣

# About This Concert

『雙城琴緣』是由與新加坡布萊德嶺交響樂團與台北城市愛樂共同演出的音樂會，以琴會友，特別邀請小提琴家游山，演出西貝流士小提琴協奏曲，管弦齊鳴，濃烈磅礴的旋律，引領聽眾與我們一起翱翔綺麗絢彩的音樂世界。

今年是台北城市愛樂蓄勢待發的一年，我們除了規律的每週排練，更邀請享譽國際的指揮家許濛心教授一起完成「琴戀。莫斯科」年度音樂會，因緣際會在許老師的牽線下，邀請和台北城市愛樂成立初衷性質相同的新加坡布萊德嶺交響樂團來臺北交流，舉辦一場音樂會。音樂無國界，兩個樂團都是全力推廣具有音樂教育意義的音樂團體，希望藉由這次的『雙城琴緣』音樂會可以激出不同的音樂火花，邀请您一同聆賞。

# 台北城市愛樂

# Taipei City Philharmonic

台北城市愛樂成立於2013年，創團賴宜佳老師鑒於弦樂的多樣化演出，能激起更多愛樂民眾的迴響，因此邀約了弦樂王博仁老師、管樂知名指揮老師陳一夫老師及民生社區管樂團指揮尤金順老師情義協演，全力推廣更具有音樂教育的特別意義與功能的演出活動，2013年6月第一次在中山堂中正廳演出，即得到熱烈的迴響，之後每年在中山堂定期舉辦音樂會，並廣邀臺灣傑出的音樂家一同合作演出，有指揮家許靜心、指揮家邱明宏、指揮家陳玟蓉、指揮家簡伯修、小提琴家朱育佑、小提琴家李商宇、手風琴演奏家陳俐瑾等。

有這麼一群老師，他們從臺灣各地聚集在臺北這座喧鬧的城市中，努力用音樂中的真、善、美來教育我們的下一代。

# 布萊德嶺交響樂團

# Braddell Heights Symphony Orchestra

布萊德嶺交響樂團(Braddell Heights Symphony Orchestra) 成立於1986年，是新加坡最成熟的社區交響樂團之一。它附屬於布萊德嶺民眾俱樂部，由來自本地及旅居新加坡的各國音樂愛好者所組成。

在音樂總監甄炎榮的努力耕耘下，布萊德嶺交響樂團從一個寥寥數人的小樂隊逐漸發展成頗具規模的交響樂團。2012年，樂團由年輕指揮陳志剛接棒。除了為樂團注入新活力外，陳志剛也成立了怡悅合唱團(Joy Chorale)，由許愛敏指導，為許多不具備聲樂背景的合唱愛好者提供了學習及演出的機會。

2015年，布萊德嶺交響樂團及怡悅合唱團於新加坡濱海藝術中心呈現了兩團聯合首演--貝多芬《第九交響曲》，並獲得好評。

# 布萊德嶺交響樂團

# Braddell Heights Symphony Orchestra

布萊德嶺交響樂團目前擁有約160名成員（包括交響樂團及合唱團），每年固定舉辦4場音樂會、小型室內樂演奏會和其他音樂教育及推廣活動，例如指揮大師班。作為一個社區團體，布萊德嶺交響樂團也致力於為國內樂壇新人提供演出的機會。自1997年起，樂團便開始舉辦“資優青年音樂家”音樂會，曾參與獨奏演出的包括李政樂（鋼琴）、吳松泉（小提琴）、婁楷文（古典吉他）及劉文榮（小號）等。

無論是從巴洛克音樂到現代音樂抑或是從古典音樂到電影音樂和爵士樂，布萊德嶺交響樂團都積極嘗試，以擴大觀眾群，讓更多民眾看到交響樂的多元性。當然，樂團也大力推崇本地作曲家的作品。許多本地作曲家皆通過布萊德嶺交響樂團發表們的作品，例如Americ Goh、陳忠義、盧紹璇、盧紹瑩以及John Sharpley。

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-05/4ba4ee9b-4404-4da0-8175-5da8d116adde/3c387f9391b94484e56852beddba7f2e29055d4377f0c8bf73eb2810b17f03c0.jpg)

# 布萊德嶺交響樂團

# Braddell Heights Symphony Orchestra

此外，為了向所有新加坡早期作曲家致敬，布萊德嶺交響樂團也在2015年新加坡歡慶50週年國慶之際，演出了梁榮平先生從未發表過並加入了合唱元素的《第二交響曲》。

在竭力為社區服務之餘，布萊德嶺交響樂團也多次有幸與知名音樂家合作，包括Helen Quach（越南）、Paul Banda（匈牙利）、張小惠（菲律賓/新加坡）、林岩（新加坡）和許靜心（台灣）等。一個社區樂團若缺少了專業音樂家的指導，水平肯定難以維持。因此，布萊德嶺交響樂團衷心感謝樂團首席游山及藝術顧問葉聰的耐心指導。

布萊德嶺交響樂團是一個為社區而組織的樂團，秉持著“音樂普及大眾”的宗旨，致力為音樂愛好者提供一個展現才藝的平台，同時也盡其所能將美好的音樂帶給每一個人。

# 指揮

# 陳志剛 Adrian Tan

畢業於新加坡國立大學戲劇系，陳志剛曾在新加坡海軍部隊出任軍官要職。在2009年，陳志剛榮獲新加坡藝術理事會海外獎學金，赴雪梨音樂學院向Imre Pallo學習指揮，並獲頒碩士文憑。在留學期間，他也參與了由各個國際知名指揮家所呈現的大師班。其中包括葉聰、許瀝心、Harold Farberman、Robert Gutter、Ovidiu Balan、Jan Cober、Neil McEwan、Gunther Herbig，等等。

陳志剛也經常受邀出任世界多個頂級樂團的客席指揮，其中包括越南國家交響樂團、深圳大劇院愛樂樂團、泰國暹羅歌劇團、泰國暹羅愛樂樂團、台灣汲音交響管樂團、荷蘭KLM樂團、馬來西亞理工大學交響樂團、新加坡華樂團和羅馬尼亞“Milhail Jora”交響樂團等等。

四歲學琴，畢業於雪梨大學，隨後赴美取得耶魯大學音樂系碩士學位，師承Erick Friedman、JiHeger、Alex Todicescu及鄭石生。游山於1984年加入新加坡青年交響樂團，由他擔任獨奏的維尼亞夫斯基第二小提琴協奏曲及帕格尼尼第一小提琴協奏曲曾兩度在新加坡國家電台節目中播出。

# 小提琴

# 游山 Yew Shan

1990年，游山入選亞洲青年管弦樂團，並受梅紐因（Yehudi Menuhin）指定為亞洲青年管弦樂團首屆巡迴演出之樂團首席。同年，游山赴比利時，於布魯塞爾皇家音樂學院繼續學習，之後又到北京的中央音樂學院及上海音樂學院繼續深造。

回國後，他加入新加坡交響樂團，並於1998-2000年間擔任樂團第一小提琴第四固定席位。游山赴美取得耶魯大學音樂系碩士學位後，游山也以獨奏家的身份先後與新加坡交響樂團、西貢愛樂樂團及布萊德嶺交響樂團合作演出，並於新加坡、澳洲及美國舉辦了多場獨奏會。2016年1月，游山受邀擔任布萊德嶺交響樂團首席。
