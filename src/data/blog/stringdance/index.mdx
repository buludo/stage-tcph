# 序

十年前的起心動念，我們集結了國小的弦樂團學生以及畢業的孩子們，在信義區的購物廣場企劃了一場快閃演出，因為這場演出之後受到許多感動的迴響與鼓舞，為了讓學生們延續愛樂的動力，因而創立了台北城市愛樂。當時一起拉琴玩樂的孩子們長大了，身旁陪伴的老師、家長們依舊，這些年來我們懷著單純分享音樂的心，不論在臺北、宜蘭、香港、日本，我們一起度過了許多難忘、珍貴的音樂回憶，十年後的今天，感動的是我們仍在舞臺上一起玩樂，對音樂的熱情不變....

保持這份愛音樂的美好，台北城市愛樂希望讓古典樂與你我的距離不再這麼遙遠，人人都能走進音樂廳聽一場我們為您安排的樂曲。舞臺上一群愛好音樂的學生以及陪伴成長的家長，從小手把手教導的專業老師們領著這些略顯生澀的學員團，或許音準差強人意、偶爾還是因緊張小出槌，但我們希望和臺下的家人朋友們，分享我們熱愛的音樂。

感謝恩師許靜心教授，不厭其煩的陪伴我們一次次的排練，總是親切隨和、滿滿的活力令人讚嘆。也是因有許教授的牽線，我們2019年認識了遠道而來的小提琴家游山老師，溫和內斂的老師總是帶著微笑，但演奏出的每顆音符深沈且震撼，餘音繚繞讓人久久不能忘懷，能在疫情苦難之後再和新加坡好朋友齊聚臺北，開心又興奮。也感謝百聞不如一見、神級的小號演奏家侯傳安教授接受邀請，相信臺上臺下的大家都很期待即將施展的神乎其技！

We believe music makes the world a better place!

我們因愛樂集結，因感動而持續努力，再次感謝有您的蒞臨，一起感受音樂的美好！

# 台北城市愛樂樂團

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-08/d328dfb4-1753-463f-ac61-66e19bbd3b64/182f1869b571eef85f9fc5405abb28760d5ecb2dfb3777f74bccc8a1d3de41f4.jpg)

台北城市愛樂成立於2012年，創團賴宜佳老師鑒於弦樂的多樣化演出，能激起更多愛樂民眾的迴響，因此邀約了弦樂王博仁老師、管樂知名指揮老師陳一夫老師及民生社區管樂團指揮尤金順老師情義協演，全力推廣更具有音樂教育的特別意義與功能的演出活動。

# 台北城市愛樂樂團

2013年6月第一次在中山堂中正廳演出，即得到熱烈的迴響，之後每年在中山堂定期舉辦音樂會，並廣邀臺灣傑出的音樂家一同合作演出，有指揮家許澣心、指揮家邱明宏、指揮家陳玟蓉、指揮家簡伯修、小提琴家朱育佑、手風琴演奏家陳俐瑾、小提琴家游山、小提琴家歐之瑀等。有這麼一群老師，他們從臺灣各地聚集在臺北這座喧鬧的城市中，努力用音樂中的真、善、美來教育我們的下一代。

2014年9月第一次在市政府親子劇場舉辦大提琴重奏音樂會，結集小小孩與老師群所編製出的50人大提琴團，首次演出即獲得大眾熱烈的回應，並應邀參與至Bellavita寶麗廣場聖誕活動、SOGO復興館的社區藝文活動演出。我們也與各地學子們做音樂交流：2016年1月及2017年2月赴香港、大阪，在香港理工大學、伊丹市立文化會館作交流演出2018年7月，城市愛樂至日本參加富士山河口湖音樂祭，於國際青少年交流音樂會演出。我們期盼以音樂來減輕生活上的壓力，用樂曲來豐富枯涸的心靈，邀請這城市的人們一起沉浸在美妙的旋律裡！

# 指揮 許瀞心

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-08/d328dfb4-1753-463f-ac61-66e19bbd3b64/79c81b92492f1f16dbff4bf934fffec6d8f7f9b2e7c1325b76e3ce6d648b8885.jpg)

她能從指揮台上將她的魄力，傳達給：樂團，及聽眾！”

-美國奧瑞岡日報

指揮家許瀞心於2003年應聘返台任職國立台灣師範大學音樂學系交響樂團指揮及指揮教授。旅美逾20載間任職美國舊金山女子愛樂交響樂團指揮暨藝術總監、密蘇里州春田市交響樂團音樂總監暨指揮、奧瑞岡州尤金市莫札特室內樂團音樂總監暨指揮、波特蘭奧瑞岡交響樂團助理指揮及明尼蘇達州之聖克勞德州立大學教授。

許指揮擔任客席指揮之演出足跡遍布南北美洲、歐亞洲及俄羅斯等地。曾與諸多獨奏家合作，包含游山、高虹、郭雅志、林昭亮、胡乃元、章雨亭、陳必先、陳宏寬、簡碧青、陳介涵、嚴俊傑、謝宛臻、吳菡、David Finckel、Steven Isserlis、Andre Watts、Gil Shaham、Sarah Chang、Gary Karr、Angela Hewitt、Tony Bennett、Maureen McGovern、Judy Collins等知名音樂家。2000-2016年夏擔任紐約州Bard College 指揮家研究院之首席客席指揮教授。現擔任國內音樂類項評委，亦數度受邀擔任新加坡全國音樂比賽評委。

近年客席指揮含2014新加坡交響管樂團、2015首爾愛樂交響樂團、2016/2022新加坡Braddell Heights交響樂團及2016越南西貢愛樂交響樂團、2018新加坡南洋藝術學院交響樂團80週年校慶音樂會、2019臺北市靜心高中管弦樂團義大利、奧地利巡演、美國辛辛那提音樂院2019暑期《莫扎特費加洛婚禮》歌劇營及2022歌劇營擔任客席指揮教授。2019率臺師大合唱團及交響樂團於高雄衛武營演出。2020科羅拉多州All State Symphony Orchestra及南密西西比州立大學交響樂團、2023堪薩斯州All State String Orchestra客席指揮教授。

近年教學相長，培育多位具指揮天份之青年，數位青年指揮家並頻獲國際指揮大獎及任職專業樂團。

自幼習琴，從小進入音樂班就讀即展現音樂天份。熱衷參與樂團演出，多次受邀至國家音樂廳、國家戲劇院、各縣市文化中心參與演出。在學習音樂之路穩紮穩打，有著深厚的基礎，曾獲選參與臺灣青少年交響樂團至歐洲巡迴演出，足跡踏遍奧地利、法國、匈牙利等國際級音樂廳，也受邀至總統府介壽音樂會參與演出。第一名進入台灣師大音樂研究所指揮組，之後多次與師範大學管弦樂團合作演出，並獲邀指揮新銳作曲家之作品發表。熱於學習的她在忙碌的工作之虞不忘學習，參加美國參加巴德大學Bard College參加指揮音樂節，受Harold Farbermann、Apo Hsu、Raymond Harvey等指揮家指導，深入地鑽研指揮之藝術。每次音樂會在舞臺上展現的指揮魅力與熱情，除在樂曲表現豐沛的生命力外，其豐富迷人的肢體語言與表情對音樂的詮釋細膩，引領臺下的每一位觀眾沈浸在音樂之中。對音樂與美感教育的培育與推動始終充滿活力，創立台北城市愛樂，希望藉由樂音與群眾作美的交流，豐富民眾的藝術生活，傳送人人愛樂的理念。

# 小提琴 游山

![image](https://cdn-mineru.openxlab.org.cn/result/2026-05-08/d328dfb4-1753-463f-ac61-66e19bbd3b64/28d64b8b48abe06724644017f7e070bc66cc7899147bc16cf02d2e3f6213b3ec.jpg)

游山四歲學琴，畢業於雪梨大學，隨後赴美取得耶魯大學音樂系碩士學位，師承Erick Friedman、Jiří Heger、Alex Todicescu及鄭石生。

游山於1984年加入新加坡青年交響樂團，由他擔任獨奏的維尼亞夫斯基第二小提琴協奏曲及帕格尼尼第一小提琴協奏曲曾兩度在新加坡國家電台節目中播出。1989年，游山獲得新加坡全國音樂比賽小提琴組(公開組)第一名，同時也獲得全場最佳獨奏員。

1990年，游山入選亞洲青年管弦樂團，並由梅紐因(Yehudi Menuhin)指定為亞洲青年管弦樂團首屆巡迴演出之樂團首席。同年，游山赴比利時，於布魯塞爾皇家音樂學院繼續學習，之後又到北京的中央音樂擊院及上海音樂學院繼續深造。回國後，他加入新加坡交響樂團，並於1998-2000年間擔任樂團第一小提琴第四固定席位。

2000年，游山赴美取得耶魯大學音樂系碩士學位，師事Erick Friedman。在求學期間，游山累積了豐富的樂團經驗，他曾擔任耶魯愛樂樂團及德州音樂節交響樂團的首席，同時也參與了許多室內樂及音樂節的演出。

除此之外，游山也以獨奏家的身份先後與新加坡交響樂團、西貢愛樂樂團、布萊德嶺交響樂團及台北城市愛樂合作演出，並於新加坡、澳洲及美國舉辦了多場獨奏會。

# 演出曲目PROGRAM

# 翠綠雄鷹

# Richard Meyer : "The Emerald Falcon"

有點像超級英雄的電影配樂風格開頭，讓聽眾聯想到飛向自由和與暗敵人戰鬥的情景，翡翠獵鷹同時也飛進了城裡、在高空中翱翔...時而鏗鏘有力的節奏、或是轉而抒情、有點夢幻的旋律，有著無限的想像空間。這首以經典的ABA形式寫作而成，樂團中的所有聲部輪流演奏出主題，旋律不間斷的一部傳遞到另一聲部，中間的慢板抒情部分，小提琴的獨奏宛如在美麗寧靜的樂團陪伴下自由翱翔。

作曲家理查·梅耶(Richard Meyer, 1952-2012)是一位全國性的暢銷作曲家，擁有超過190首的原創作品以及編曲，他也是一位音樂教育家，在小學、國中和高中教等公立學校教授弦樂學生持續了三十五年之久。

他任教於加州天普市的橡樹大道中學Oak Avenue Intermediate School指揮管弦樂團的二十二年間，從僅有29名學生的小型室內樂擴張到有200名團員的樂團，是天普市Temple City甚至是南加州弦樂教學的大力推動者。

# 米堯《普羅旺斯組曲》第一樂章

# "Animé" From Suite provençale, Op. 152

米堯(Darius Milhaud,1892-1974) 生於普羅旺斯地區艾克斯(Aix-en-Provence)，最初是一名小提琴家，後來開始創作，成為法國六人組Les Six重要的現代作曲家之一。

米堯是20世紀產量最大的作曲家之一，他的風格深受爵士樂以及新古典主義樂派的影響。於1936年創作的交響樂作品《普羅旺斯組曲》Suite provençale是將作曲家敏銳的平衡感、節制的音樂風格展現，從18世紀的普羅旺斯主題中汲取靈感，充滿當時風行的新古典主義風格。

八個樂章快慢交替進行著的芭蕾舞組曲，有點樸實但融合了戲劇性張力，吸引著聽眾的注意力。今天我們所演奏的第一樂章，Animé活潑、動感的，樂曲一開始銅管之間的多調性的和聲與樂團此起彼落戲劇性的節奏，讓人感受到譜上的音符從平面變成立體，動感、急切地向前跳躍，呈現不同以往的現代音樂特色。

# 演出曲目PROGRAM

# 布魯赫第一號g小調小提琴協奏曲

# Violin Concerto No.1 G minor Op.26

第一樂章 前奏曲，中庸的快板 Vorspiel：Allegro moderato

第二樂章 慢板 Adagio

第三樂章 終曲，活力充滿的快板 Finale : Allegro energico

德國作曲家布魯赫 (Max Christian Friedrich Bruch, 1838 - 1920) 孩提時代已顯露出過人音樂天賦，兒時的布魯赫可以說是圍繞沈浸在孟德爾頌、蕭邦、羅西尼和貝多芬等一干浪漫樂派大師的音樂之中，受浪漫主義影響甚深的他，終生都堅持一貫的浪漫風格。布魯赫不僅是位相當成功的作曲家，也是知名指揮和教師，佛漢·威廉斯 (Vaughan Williams 1872-1958)、雷史畢基 (Ottorino Respighi 1879-1936) 等知名作曲家皆是他的學生。儘管他自己是鋼琴家，但他卻說自己很喜愛小提琴「因為小提琴比起鋼琴更適合吟唱旋律，而旋律正是音樂的靈魂」。

第一號g小調小提琴協奏曲於1864年著手譜寫，1867年完成，呈獻給友人約瑟·姚阿欣(Joseph Joachim，1831-1907)，是他三首小提琴協奏曲當中最受喜愛的一首，更是浪漫主義作品的小提琴協奏曲代表作。雖然此曲採取傳統的三樂章構造，但其樂曲形式相當獨特，全曲三樂章一氣呵成。全曲充滿絢爛豪華的氛圍，也充滿憂鬱抒情的情緒。第一樂章初時很柔和，短短的引子恍如讚美詩般小提琴從中浮現。從霸氣十足的小提琴獨奏，帶入沉思、抒情的第二樂章，展現了小提琴的圓潤音色，深刻而豐富的感情，流露出的旋律感人肺腑，令人流連忘返。活潑有朝氣的第三樂章，演奏出剛健而稜角分明的鮮明旋律，與前面平靜的樂章成對比，熱情狂放，華麗的結束全曲。

# 演出曲目PROGRAM

# 威尼斯狂歡節變奏曲

Jean-Baptiste Arban (1825-1889) :

Variations on "The Carnival of Venice"

這首堪稱浪漫樂派小號作品的經典之作—《威尼斯狂歡節幻想變奏曲》的作曲者阿爾班（Jean-Baptiste Arban，1825-1889），是一位聲名卓著的作曲家、小號演奏家、指揮家、教育家，是當代小號學派的奠基者，他給音樂院學生的教本“Arban's Complete Conservatory Method”可說是「小號手的聖經」。因受到帕格尼尼（Niccolò Paganini）在小提琴上的精湛技巧的啟發，他使短號發揮精湛的技巧而成為一種獨奏樂器。

《威尼斯狂歡節》改編自拿玻里的民謠《哦，媽媽》O Mamma, Mamma Cara，帕格尼尼對它的熱愛，1829年將原曲的基礎上創作了一首有20個變奏的小提琴作品。

今天將要演出的是著名的俄羅斯小號演奏家Sergei Nakariakov所改編的版本，主題加上8個變奏，樂風活潑生動，想像徜徉在色彩明亮、歡慶熱烈，狂歡節載歌載舞的景象。一系列的主題和變奏，透過小號雙吐、三重吐音、大跳音程和快速音群的華麗技巧展現，就讓狂歡節的熱烈非凡、絢爛奪目以短號的炫彩樂音留下深刻難忘的印象。

# 拿坡里民謠變奏曲

# "Napoli, Canzone Napolitana Con Variazioni"

大家耳熟能詳的拿坡里民謠《登山纜車》Funiculí, Funiculá，是1880年為了維蘇威火山山頂的纜車開通所作的歌曲，活潑輕快、塔朗泰拉風格的曲子自此之後受到許多作曲家喜愛引用至作品當中。貝爾施泰特（Herman Bellstedt, 1858-1926）是美國著名的短號獨奏家，曾擔任辛辛那提音樂學院的管樂教授，將民謠作為主題，以及兩個變奏的短號演奏曲，此變奏曲的大獲成功，不只有短號獨奏版本，還有改編給不同樂器與編制來演奏。

# 帶我飛向月球

# "Fly Me to the Moon"

《Fly Me to the Moon》原是由巴特·霍華德Bart Howard寫於1954年的一首原名《In Other Words》(換句話說)華爾茲舞曲，從那時起，它開始成為一首多次被翻唱的爵士樂經典曲。法蘭克·辛納屈Frank Sinatra的1964年錄製版本與當時美國推行「阿波羅10號」登月計劃密切相關，故這首歌推出之後大受歡迎，甚至成為此年代的代表曲。
感謝謝宇婷老師為此曲改編為小號與管弦樂團演奏的版本!

# 演出曲目PROGRAM

# 威風凜凜進行曲

# Pomp and Circumstance Op. 39, March No.1

《威風凜凜第一號進行曲》創作於1901年，該進行曲的標題來自於莎士比亞的劇作《奧賽羅》第三幕第三場的臺詞：「…永別了，長嘶的駿馬、銳厲的號角、驚魂的轟鼓、刺耳的橫笛、莊嚴的大旗和一切戰陣上的威儀 (Pride, pomp, and circumstance of glorious war!) 英國作曲家艾爾加共寫了五首威風凜凜進行曲，唯有第一號從首演就大受歡迎，甚至在1902年，英王愛德華七世加冕典禮時演奏的加冕頌歌中，將中段Trio部分進行了修改加入歌詞，將之命名為「希望與榮耀的國度」，從此，此曲就成了大英帝國的第二國歌，成為每年大英國協盃足球賽、皇家愛樂廳每年逍遙音樂會The Proms裡必演的曲目。

這首進行曲氣勢磅礴、振奮人心，也是因成為日本電視動畫「我們這一家」的片尾曲，更能體會到它家喻戶曉、老少咸宜的魅力。

# 第二號舞曲

# Danzón No. 2

作曲的靈感是來自於作曲家馬奎茲 (Arturo Márquez Navarro, 1950-) 在墨西哥各地旅行時，接觸到原本發祥於古巴、後來在墨西哥也廣為流傳大受歡迎的舞曲 (Danzon) 音樂與舞蹈。
